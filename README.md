# TB-001A 双尾蝎无人机机库整备 3D 场景 (Twin-Tailed Scorpion Hangar)

基于 **Three.js (WebGL2)** 构建的腾盾科创 **TB-001A「双尾蝎」大型三发察打一体无人机** 机库全弹整备高精度 3D 交互场景。

## 核心特性

- **100% 考证级气动与涂装建模**：
  - 折线棱边机头、高耸卫通整流背脊、平底船型下机身放样曲面，支持 **珠海航展官方三色涂装** 与 **`JD-1052` 实战低可视度涂装** 实时切换。
  - 精确还原前起落架前置 + 海鸥灰球形 `EO/IR-380` 多光谱光电转塔布局、20 米平直梯形层流机翼、拉丝铝本色桨毂整流罩、3 叶弯刀螺旋桨、短舱水滴形整流鼓包与 5 道竖向散热百叶鳃、尾推第三发、直立双垂尾及下反腹鳍。
- **6 挂点双联复合挂架与 12 枚实弹**：
  - 翼下混挂 `CM-502KG` 空地导弹、`FT-9` 飞腾精确制导炸弹与 `AR-4` 重型多模导弹，机头前右侧同步还原航展 5 级静展弹药托架阵列。
- **电影级物理材质与光影管线**：
  - 程序化生成 2K 切线空间法线贴图（3×3 Sobel）与哑光军用聚氨酯粗糙度贴图。
  - 集成 `GTAOPass` 全局环境光遮蔽、实体 `RectAreaLight` 机库顶置线性柔光灯箱、2048×2048 软阴影、平面衰减地面反射与 ACES Filmic 色调映射，支持 **天光 / 黄昏 / 精检** 三种机库光影模式。
- **高精度航空试验机库与保障设备**：
  - 宽翼缘 H 型钢立柱、空间三角管桁架屋顶、双梁桥式起重机、半透明聚碳酸酯分段机库大门（`10-1 / 10-2 / 10-3`）、航空铝包边黑箱、28V 地面电源车及管式铝合金登高梯。
- **3A 军工战术交互界面**：
  - 支持 6 组电影运镜机位（`[1]`–`[6]`）、翼下挂点点击/悬停 Gunsmith 参数检视、`[E]` 三发地面试车、`[T]` 光电激光照射、`[F]` 全机飞控舵面自检、`[N]` 航行滑行灯、`[C]` 空间引线标注、`[M]` 程序化合成音效及 `[H]` 纯净摄影模式。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
